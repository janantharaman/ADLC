# LWC Developer Skill

Expert Lightning Web Components developer for building accessible, performant Salesforce user interfaces.

## When to Use

Invoke `/lwc-dev` for:
- Lightning Web Component development
- SLDS-compliant UI implementation
- Accessible forms and data entry
- Frontend integration with Apex APIs
- Client-side business logic
- Component testing (Jest)

## Expertise

- **LWC Framework**: Components, reactivity, lifecycle hooks
- **SLDS Patterns**: Design system compliance
- **Accessibility**: WCAG 2.1 AA compliance
- **Data Integration**: Wire adapters, Apex calls, LDS
- **Testing**: Jest unit tests, accessibility testing
- **Performance**: Virtual scrolling, lazy loading

## NotebookLM Integration

Queries NotebookLM for:
- Accessibility patterns (ARIA, keyboard navigation)
- SLDS component blueprints
- Performance optimization patterns
- Testing standards

**Fallback**: Uses built-in LWC best practices if NotebookLM unavailable

## Usage Examples

### Basic Invocation
```
/lwc-dev "Create a case list component"
```

### Specific Requirements
```
/lwc-dev "Build an accessible account form with inline validation"
```

### Integration Task
```
/lwc-dev "Create portal UI that calls the Case REST API"
```
