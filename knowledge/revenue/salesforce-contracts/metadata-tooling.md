# Salesforce Contracts (CLM) — Metadata & Tooling

## Metadata API Types

### ClauseCatgConfiguration
Clause category configuration for the clause library.
- **API version:** 57.0+
- **Wildcard support:** No

---

### ContextUseCaseMapping
AI context service mapping for contract creation or extraction.
- **API version:** v61.0+
- **Wildcard support:** Yes (`*` in package.xml)

**Fields:**
| Field | Type | Required | Notes |
|---|---|---|---|
| `contextDefinitionName` | string | Yes | References a ContextDefinition component |
| `mappingName` | string | Yes | e.g., `OppToCntrHydrationMapping` |
| `mappingType` | ContextMappingType | Yes | `Hydration` or `Persistence` |
| `masterLabel` | string | Yes | UI display name |
| `referenceObjectName` | string | No | Source object (e.g., `Opportunity`) |
| `referenceObjectRecordType` | string | No | v61.0+ record type on source |
| `targetObjectCustomFieldName` | string | No | Custom lookup field linking target to source |
| `targetObjectName` | string | No | Destination object (typically `Contract`) |
| `targetObjectRecordType` | string | No | Record type on target |
| `useCaseType` | ContextUseCaseType | Yes | `ContractCreationOrUpdation` or `ContractExtraction` |

**Sample:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<ContextUseCaseMapping xmlns="http://soap.sforce.com/2006/04/metadata">
  <contextDefinitionName>TestDefName</contextDefinitionName>
  <mappingName>TestMapName</mappingName>
  <mappingType>Hydration</mappingType>
  <masterLabel>TestMLabel</masterLabel>
  <referenceObjectName>Opportunity</referenceObjectName>
  <referenceObjectRecordType>TestOppRT</referenceObjectRecordType>
  <targetObjectCustomFieldName>SourceOpportunityId</targetObjectCustomFieldName>
  <targetObjectName>Contract</targetObjectName>
  <targetObjectRecordType>TestOppRT</targetObjectRecordType>
  <useCaseType>ContractCreationOrUpdation</useCaseType>
</ContextUseCaseMapping>
```

### ContractType
Groups contracts with similar characteristics.
- **File suffix:** `.contractType`
- **Directory:** `contractTypes/`
- **API version:** 54.0+
- **Wildcard support:** Yes

**Fields:**
| Field | Type | Required | Notes |
|---|---|---|---|
| `masterLabel` | string | Yes | Display name |
| `isDefault` | boolean | No | Default: `false` |
| `subTypes` | string | No | Linked Contract record type names |
| `contractTypeConfigs` | ContractTypeConfig[] | No | Config key/value pairs |

**ContractTypeConfig sub-fields:**
| Field | Required | Notes |
|---|---|---|
| `configType` | Yes | One of 30+ values (see list below) |
| `configValue` | Yes | String value for the config |
| `usageType` | No | `DocumentSetting`, `Reconciliation`, `Redlining`, `SignatureSetting` |

**All configType values:**
`ActivateObligationsBasedOnContractStatus`, `Append0ToAutoNbrEmbeddedSect`, `AsyncCheckInEnabled`, `AutoGenDocOnContractCreation`, `AutoGenDocOnContractUpdate`, `AutoGenerateDocFileType`, `CheckInDocFileType`, `CompareContractVersionsEnabled`, `ContractDocumentDownloadOption`, `ContractSignatureDeclinedSts`, `ContractSignatureExpiredStatus`, `ContractSignatureVoidedStatus`, `ContractSignedStatus`, `CreateDocSectionsDocxTemplates`, `DefaultTemplateName`, `DocuSignAccountBrand`, `DocuSignExpireEnabled`, `DocuSignExpireWarning`, `DocuSignExpiresAfter`, `DocuSignReminderDelayinDays`, `DocuSignReminderEnabled`, `DocuSignReminderFrequency`, `DocuSignUseAccountDefaultNtfcn`, `DocumentFileNameFormat`, `DocumentTemplateFilterClass`, `EmailNotificationOnDocumentGeneration`, `ExternalReviewRequired`, `ImportTargetContractStatus`, `InclWordTrackChgReconciliation`, `InclWordTrackChgSectionContent`, `InternalReviewRequired`, `NotifyDocTemplateVerChgStatus`, `PrivateExternalReviewCompletionSite`, `TrackContractRedlines`, `WordTrackChangesDisplayColor`

**Sample:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<ContractType xmlns="http://soap.sforce.com/2006/04/metadata">
  <masterLabel>Standard_Agreement</masterLabel>
  <isDefault>true</isDefault>
  <subTypes>ContractLifecycleManagement</subTypes>
</ContractType>
```

### DocumentTemplate
Document template definition for dynamic generation.
- **File suffix:** `.dt`
- **Directory:** `documentTemplates/`
- **API version:** 59.0+
- **Wildcard support:** Yes
- **Extends:** `MetadataWithContent` (includes `content` and `fullName` fields)

**Key fields:**
| Field | Type | Required | Notes |
|---|---|---|---|
| `type` | DocumentTemplateType | Yes | `Web`, `MicrosoftWord`, `Microsoft365Word`, `MicrosoftPowerpoint`, `HTMLArchive` |
| `tokenMappingType` | TokenMappingType | Yes | `JSON` or `SalesforceObject` |
| `masterLabel` | string | No | Display label |
| `documentGenerationMechanism` | DocumentGenerationMechanism | No | `ClientSide` (default) or `ServerSide` |
| `tokenMappingMethodType` | TokenMappingMethodType | No | `ContextService` (default), `CustomClass`, `OmniDataTransform` |
| `extractOmniDataTransformName` | string | No | Extract DataTransform bundle |
| `mapperOmniDataTransformName` | string | No | Mapper DataTransform bundle (v56.0+) |
| `contextDefinitionName` | string | No | Context service definition (v65.0+) |
| `contextMappingName` | string | No | Context service mapping (v65.0+) |
| `ContextFilterName` | string | No | Context filter (v66.0+) |
| `customClassName` | string | No | Custom Apex class |
| `usageType` | DocumentTemplateUsageType | No | `Contract_Lifecycle_Management`, `Revenue_Lifecycle_Management` |
| `targetTokenObject` | TargetTokenObject | No | `CONTRACT`, `OPPORTUNITY`, `ORDER`, `QUOTE` |
| `targetTokenItemObject` | TargetTokenItemObject | No | `OPPORTUNITY_LINE_ITEM`, `ORDER_LINE_ITEM`, `QUOTE_LINE_ITEM` |
| `isActive` | boolean | No | Default: `false` |
| `status` | DocumentTemplateStatus | No | `Draft`, `Active`, `Archived` |

**Sample:**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<DocumentTemplate xmlns="http://soap.sforce.com/2006/04/metadata">
  <name>Sample</name>
  <type>MicrosoftWord</type>
  <documentGenerationMechanism>ServerSide</documentGenerationMechanism>
  <tokenMappingMethodType>OmniDataTransform</tokenMappingMethodType>
  <tokenMappingType>JSON</tokenMappingType>
  <extractOmniDataTransformName>extractorv1</extractOmniDataTransformName>
  <mapperOmniDataTransformName>mapperv1</mapperOmniDataTransformName>
  <usageType>Contract_Lifecycle_Management</usageType>
  <targetTokenObject>CONTRACT</targetTokenObject>
  <isActive>true</isActive>
  <status>Active</status>
  <masterLabel>Sample_v1</masterLabel>
  <uniqueName>Sample_1</uniqueName>
  <versionNumber>1</versionNumber>
</DocumentTemplate>
```

## Tooling API Objects

### ContractTypeConfig (Tooling)
Accessible via Tooling API for developer tooling.
- **SOAP:** `create()`, `delete()`, `describeSObjects()`, `query()`, `retrieve()`, `update()`, `upsert()`
- **REST:** `DELETE`, `GET`, `HEAD`, `PATCH`, `POST`, `Query`
- Master-detail relationship: `ContractTypeId` → `ContractType`
- Additional Tooling-only `UsageType` value: `ObligationSetting`

**Query via Tooling REST:**
```
GET /services/data/v67.0/tooling/query/?q=SELECT+Id,ConfigType,ConfigValue,UsageType+FROM+ContractTypeConfig+WHERE+ContractTypeId='{contractTypeId}'
```

## DocumentTemplateConfig (Migration Support)
Internal shadow object for migrating document templates between environments.
- `DeveloperName` references `DocumentTemplate.UniqueName`
- Used for import/export in managed packages
- Directory: not applicable (internal use)
- For standard deployments, use the `DocumentTemplate` metadata type directly
