Roadmap diagrams help organizations plan and visualize the strategic implementation of capabilities, components, features, and systems over time. These diagrams enable architects and project managers to streamline resource planning, optimize budgeting, and enhance collaboration between business and technical teams. They provide a clear view of implementation order, dependencies, and priorities, helping stakeholders understand the phased approach to delivering complex Salesforce solutions.

This section contains 6 reference diagrams related to roadmaps:

| Diagram Name | Description |
| --- | --- |
| [Capability Roadmap](/docs/architect/reference-diagrams/guide/capability-roadmap) | A visual roadmap that streamlines resource planning and budgeting by grouping capabilities and identifying implementation order, dependencies, and value. |
| [Component Roadmap](/docs/architect/reference-diagrams/guide/component-roadmap) | A visual roadmap that optimize resource planning and budgeting by identifying system functionality, relevant features, implementation order, timeframes, and stakeholder dependencies. |
| [Feature Roadmap](/docs/architect/reference-diagrams/guide/feature-roadmap) | A visual roadmap that enhances collaboration between business and technical teams by identifying feature implementation order, dependencies, and additional functionality for planning purposes. |
| [Agentforce Release Plan](/docs/architect/reference-diagrams/guide/generative-ai-release-plan) | A diagram detailing the deliverables for an initial generative AI project release. |
| [Agentforce Roadmap](/docs/architect/reference-diagrams/guide/generative-ai-roadmap) | An example roadmap showing components for rolling out AI across a Salesforce Customer 360 implementation. |
| [System Roadmap](/docs/architect/reference-diagrams/guide/system-roadmap) | Simplify resource planning and budgeting by identifying system implementation order, dependencies, and feature priorities. |
