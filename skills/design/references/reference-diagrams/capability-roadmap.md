## Description

A visual roadmap that streamlines resource planning and budgeting by grouping capabilities and identifying implementation order, dependencies, and value.
For each capability in this diagram, it is common to have a dedicated [Component Roadmap](/docs/architect/reference-diagrams/guide/component-roadmap.html) to drill into the details of the delivery.
