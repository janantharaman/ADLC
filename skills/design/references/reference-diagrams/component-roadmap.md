## Description

A visual roadmap that optimize resource planning and budgeting by identifying system functionality, relevant features, implementation order, timeframes, and stakeholder dependencies.
This diagram is usually used as a detail view of one box in a [Capability Roadmap](/docs/architect/reference-diagrams/guide/capability-roadmap.html).
For each component in this diagram, it is common to have a dedicated [Feature Roadmap](/docs/architect/reference-diagrams/guide/feature-roadmap.html) to drill into the details of the delivery.
