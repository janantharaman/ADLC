## Description

A visual roadmap that enhances collaboration between business and technical teams by identifying feature implementation order, dependencies, and additional functionality for planning purposes.
This diagram is usually used as a detail view of one box in a [Component Roadmap](/docs/architect/reference-diagrams/guide/component-roadmap.html).
